# SecureCopilot 
AI-Powered DevSecOps Toolchain for Python Security

## Features
- Real-time vulnerability detection (OWASP Top 10)
- Local LLM explanations (CodeLlama via Ollama)
- VS Code extension (.vsix)
- React dashboard with JWT auth
- PostgreSQL vulnerability tracking

## Stack
FastAPI | React.js | PostgreSQL | TypeScript | Semgrep | Ollama
